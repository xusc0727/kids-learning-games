# 小小寓言屋

状态：25 篇固定故事与 AI 个性故事生成均已实现。

面向 3～6 岁儿童家庭，提供“成人操作、儿童收听、亲子互动”的寓言故事体验。详细方案见 [`../../docs/产品规划/AI寓言故事工坊.md`](../../docs/产品规划/AI寓言故事工坊.md)。

当前版本包含：

- 五大领域各 5 篇固定故事，共 25 篇。
- 成人填写年龄段、成长领域、最近事件和可选偏好后，通过 DeepSeek 生成个性故事。
- 故事阅读、收藏、亲子问题和现实行动。
- 未登录设备可找回最近 12 篇个性故事；成人确认同步后可保存到家庭。
- 当前只生成文字故事，不生成插图或语音。

启用个性故事需要同时配置 `AI_STORY_GENERATION_ENABLED=true`、`DEEPSEEK_API_KEY` 和可用的 MySQL。开关为 `false` 时，页面生成按钮保持禁用，直接请求生成接口也会被拒绝。API Key 只允许填写在受限环境文件中，不得放入前端代码或提交 Git。

家长填写的原始事件、小名、偏好和故事氛围只用于本次 DeepSeek 请求，不写入项目数据库；生成后的故事保存到 `stories` 表。页面和法律文档均提示不要填写真实姓名、联系方式、住址、学校或医疗诊断等不必要信息。

系统预设故事的源文件为 `database/fixed-stories.mjs`，执行 `npm run db:migrate` 时会同步到 `stories` 表。页面运行时通过 `/api/stories/fixed` 读取，不再从前端 JavaScript 读取故事正文。
