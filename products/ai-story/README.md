# 小小寓言屋

状态：25 篇固定故事已上线；个性故事生成在公安联网备案期间暂停。

面向 3～6 岁儿童家庭，提供“成人操作、儿童收听、亲子互动”的寓言故事体验。详细方案见 [`../../docs/产品规划/AI寓言故事工坊.md`](../../docs/产品规划/AI寓言故事工坊.md)。

当前公开版本包含：

- 五大领域各 5 篇固定故事，共 25 篇。
- 故事阅读、收藏、亲子问题和现实行动。
- 未登录收藏保存在当前浏览器，成人确认同步后可保存到家庭。
- 不生成文字、插图或语音，也不接收用户故事素材。

个性故事生成实现暂时保留在服务端，但 `AI_STORY_GENERATION_ENABLED` 默认为 `false`，公开页面不提供入口，直接请求生成接口也会被拒绝。重新开放前需先完成相应合规准备，再显式开启。API Key 只允许填写在受限环境文件中，不得放入前端代码或提交 Git。

系统预设故事的源文件为 `database/fixed-stories.mjs`，执行 `npm run db:migrate` 时会同步到 `stories` 表。页面运行时通过 `/api/stories/fixed` 读取，不再从前端 JavaScript 读取故事正文。
