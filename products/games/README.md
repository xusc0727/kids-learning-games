# 童趣游戏乐园

故事化游戏世界入口为 `index.html`。截至 2026-08-03，“童趣森林”第一季五章已经全部可玩，自由游戏区共有 11 款学习游戏。

## 当前完成情况

- 五章使用同一条森林成长故事串联，按顺序解锁，每章包含三项适龄任务和一个通关反馈阶段。
- 第一章至第五章已经全部实现，不再是只有第一章的演示原型。
- 主线场景、角色、物品、地点和奖励使用项目内原创图片素材，不再依赖不同系统显示不一致的 Emoji。
- 第一章完成后获得 3 件装饰；之后每完成一章再获得该章全部 3 件装饰，第一季共 15 件。
- 森林地图提供装饰背包。儿童可以选择装饰后点击地图自由摆放，也可以按住拖动、重新定位或收回背包。
- 章节进度、奖励解锁和装饰位置都保存在浏览器本地，刷新页面后仍会恢复。
- 已检查手机竖屏、iPad 竖屏、iPad 横屏和桌面宽屏。背包入口、背包弹窗和摆放提示均有对应适配。
- 自由游戏区新增 6×6“舒尔特方格”，按照 1～36 顺序点击，完整通关后记录日期时间和用时。
- 舒尔特方格在当前浏览器保存最近 100 次记录，汇总第一次、最近一次和最快纪录，并绘制最近 10 次趋势。
- 当前全项目自动化测试为 61 项，其中舒尔特方格专项测试为 6 项。

## 舒尔特方格

- `schulte/index.html`：开始页、6×6 游戏页、通关反馈和速度历史。
- `schulte/styles.css`：儿童数字练习册视觉、6×6 响应式棋盘和历史趋势布局。
- `schulte/game.js`：顺序判定、前台计时、后台暂停、完整通关记录和历史渲染。
- `schulte/logic.mjs`：数字洗牌、记录校验、100 条上限、汇总和进步文案等可测试逻辑。
- 历史保存在浏览器 `localStorage` 的 `playmori-schulte-history-v1` 项中，不上传服务器。
- 只记录 1～36 完整通关；中途返回或刷新不写入历史。时间以 0.1 秒显示，设备本地时间用于历史日期。
- 点过的数字保持与未点数字相同的文字、底色和普通边框，避免通过置灰降低寻找难度；只有最近一次点对的数字显示红框，下一次点对时红框随之移动。

## 童趣森林第一季

- `index.html`：森林首页、第一季章节地图和第一章任务界面。
- `home.css`：绘本剪纸风格场景、任务弹窗和移动端适配。
- `world.js`：序章、第一章整理、图形搭建、情绪回应、整组奖励领取和第一章存档。
- `chapters.js`：第二至第五章的故事任务、顺序解锁、整组奖励、终章庆典和五章森林状态。
- `decorations.js`：装饰背包、章节奖励解锁、地图自由摆放、拖动、收回和位置存档。
- `assets/forest/`：童趣森林原创场景、角色和物品图集；页面加载优化后的 WebP，透明 PNG 与生成底稿保留在同目录便于后续迭代。
- 第一章进度保存在浏览器 `localStorage` 的 `playmori-forest-v1` 项中。
- 第二至第五章进度保存在 `playmori-forest-chapters-v1` 项中，并兼容已经完成的第一章记录。
- 装饰位置保存在 `playmori-forest-decorations-v1` 项中；每章完成后获得该章全部三件装饰。
- “重新体验整个故事”会在成人确认后清除五章本地进度。

### 第一季章节

1. 森林新家：生活分类、图形空间与情绪回应；奖励为花箱、暖灯和门环。
2. 彩虹集市：食物分类、按数取物与数量比较；奖励为彩旗、果篮和铃铛。
3. 叮当车站：颜色倾听、方位顺序与连续指令；奖励为三种火车装饰。
4. 探索山谷：视觉寻找、路线规划与植物生长顺序；奖励为三种花朵装饰。
5. 友谊舞台：社会情绪、故事排序与节奏模仿；奖励为三种舞台装饰。

### 奖励与装饰规则

1. 通关时不再三选一，该章全部三件装饰会一起进入背包。
2. 打开地图左上角的装饰背包，选择一件装饰，再点击森林中的目标位置完成摆放。
3. 已摆放装饰可以按住拖动；背包中也提供“换个位置”和“收回”操作。
4. 装饰坐标使用地图百分比保存，能够随手机、平板和桌面画面尺寸缩放。
5. 旧版本中已经完成的章节会自动获得该章全部装饰，不要求重新通关。

## 目录约定

```text
games/
├── index.html、home.css           # 游戏中心首页
├── assets/                        # 图片等静态资源
├── shared/                        # 多款游戏共享的代码和样式
└── <game>/                        # 单款游戏
    ├── index.html
    ├── styles.css                 # 可选，独立样式
    ├── game.js
    └── logic.mjs                  # 可选，可测试的纯逻辑
```

新增游戏时：

1. 使用简短英文目录名。
2. 页面统一命名为 `index.html`，逻辑统一命名为 `game.js`。
3. 只被一款游戏使用的样式和资源留在该游戏目录。
4. 被多款游戏使用的代码和样式放入 `shared/`。
5. 返回游戏中心统一使用相对链接 `../`。
