# 童趣游戏乐园

现有 10 款静态学习游戏的完整产品模块，入口为 `index.html`。

## 目录约定

```text
games/
├── index.html、home.css           # 游戏中心首页
├── assets/                        # 图片等静态资源
├── shared/                        # 多款游戏共享的代码和样式
└── <game>/                        # 单款游戏
    ├── index.html
    ├── styles.css                 # 可选，独立样式
    └── game.js
```

新增游戏时：

1. 使用简短英文目录名。
2. 页面统一命名为 `index.html`，逻辑统一命名为 `game.js`。
3. 只被一款游戏使用的样式和资源留在该游戏目录。
4. 被多款游戏使用的代码和样式放入 `shared/`。
5. 返回游戏中心统一使用相对链接 `../`。
