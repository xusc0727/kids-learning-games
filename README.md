# 童趣游戏乐园

一组适合 4 岁左右儿童的认知小游戏。目前包含彩虹餐厅、森林迷宫、找不同、动物图形数独和动物排排队五款游戏。

## 直接游玩

双击 `index.html` 即可打开游戏乐园首页，再选择想玩的游戏。推荐使用 Chrome、Edge 或 Safari。

也可以在项目目录启动本地服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 已实现内容

- 颜色、形状、数量、大小比较、果蔬分类和规律推理
- 每轮 8 位动物顾客，按“热身—进阶—挑战”逐步加难
- 后半程加入颜色＋形状双条件，选项由 3 个增加到 4 个
- 连续答错两次后提供语音和视觉提示
- 点击选择与拖拽进餐盘两种操作
- 中文语音读题与重复播放
- 温和的错误提示，不扣分、不设置失败
- 星星奖励、完成庆祝和随机动物贴纸
- 手机、平板和电脑自适应布局
- 减少动态效果的系统偏好支持

### 森林寻宝队

- 共15关：5关7×7、5关9×9、5关12×12，包含岔路和死胡同
- 首页可直接选择基础、进阶或大迷宫挑战的起点
- 方向键、键盘方向键和触屏滑动操作
- 收集食物、寻找钥匙、绕开水坑、启动机关与按顺序收集
- 路口提示、中文语音和温和的障碍反馈
- 训练方向认知、空间观察、路线规划和任务顺序

### 森林找不同

- 20个不同主题的矢量插画关卡，每关固定5处不同
- 两幅大图采用上下排列，所有关卡增加了丰富的非差异装饰元素
- 可点击任意一侧图片，找对后双图同时圈出
- 差异包含颜色、数量、方向、缺失物品和局部造型
- 提供语音反馈和逐步提示，不计时、不扣分

### 动物图形数独

- 20关4×4动物图形数独，所有题盘均为唯一解
- 难度从补1格逐步增加到10个空格
- 训练行列观察、2×2区域判断和排除推理
- 支持选格、选动物、温和纠错和自动填写一格

### 动物排排队

- 20关顺序推理，动物数量从3只逐步增加到5只
- 每关自动语音播报全部线索，并支持单条重听
- 包含最左、最右、左右关系、紧邻和中间位置
- 所有线索组合都经过唯一排列验证

## 项目结构

- `index.html`、`home.css`：游戏乐园首页与可扩展游戏菜单
- `restaurant.html`、`styles.css`、`game.js`：彩虹餐厅游戏
- `maze.html`、`maze.css`、`maze.js`：森林迷宫游戏
- `difference.html`、`difference.css`、`difference.js`：森林找不同游戏
- `sudoku.html`、`sudoku.css`、`sudoku.js`：动物图形数独游戏
- `lineup.html`、`lineup.css`、`lineup.js`：动物排排队游戏
- `assets/watermelon.svg`：与颜色、形状认知一致的完整西瓜图标
- `assets/sandwich.svg`：轮廓清晰的三角形三明治图标
- `assets/treasure-chest.svg`：在不同设备上显示一致的木质宝箱图标

游戏没有构建步骤或必须安装的第三方依赖。在线时会加载一款装饰性中文字体；离线时会自动使用设备自带字体，不影响游玩。
