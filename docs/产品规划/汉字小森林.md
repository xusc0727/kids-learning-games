# 汉字小森林产品方案

## 一句话定位

通过大字卡、普通话发音、图形联想和无压力小游戏，帮助 3～6 岁儿童在生活经验中自然认识常见汉字。

## 使用对象与原则

- 直接用户：3～6 岁儿童，建议成人在旁陪伴。
- 首要目标：建立“字形—读音—图形—词语—生活场景”的联系。
- 不以提前完成小学识字量为目标，不做默写、速度排名或错误惩罚。
- 汉字卡提供足够大的触摸区域和字形，儿童可以反复点、反复听。
- 语音由浏览器普通话朗读能力提供，不录制儿童声音。

## 首版内容

| 主题 | 汉字 | 学习连接 |
| --- | --- | --- |
| 自然朋友 | 日、月、山、水、火、木 | 天空、山水、树木与安全经验 |
| 动物伙伴 | 鸟、鱼、马、牛、羊、虫 | 常见动物外形和动作 |
| 我的身体 | 人、口、手、脚、眼、耳 | 身体部位和日常动作 |
| 我的家人 | 爸、妈、家、我、你、他 | 家庭称呼与人际表达 |
| 大小方向 | 大、小、上、下、左、右 | 比较、空间和方向经验 |

共 30 个汉字，每个字包含：

- 汉字和拼音；
- 一个关联图形；
- 一个常见词语；
- 一句适合幼儿理解的短句；
- 一条观察字形的联想提示；
- 内容难度和主题顺序。

## 核心体验

### 认一认

儿童按主题浏览字卡。点击字卡后会看到大字、图形、拼音、词语和短句，并自动听到“汉字 + 词语”的普通话发音。儿童或成人可以把这个字标记为“我认识了”。

### 找一找

每次练习只有 5 小轮，随机组合三种方式：

- 看图找字；
- 听音找字；
- 看词语联想汉字。

每轮从三个汉字中选择。选错时只提示再看或再听，不扣分；选对后朗读汉字和词语。结束时只反馈完成了五次寻找，不做能力评分。

## 数据与技术

- 内容表：`literacy_characters`。
- 内容源文件：`database/literacy-characters.mjs`。
- 内容接口：`GET /api/literacy/characters`。
- 迁移与同步：`npm run db:migrate` 自动创建表并同步 30 个汉字。
- “我认识了”进度：保存在当前浏览器 `localStorage`，首版不上传数据库。
- 不登录、不建立儿童档案、不采集录音。

## 后续方向

- 根据真实儿童使用情况调整字形提示和词语难度。
- 增加按年龄建议的学习顺序，而不是强制关卡。
- 增加字与字组合成词的小游戏。
- 评估是否加入真人发音资源，避免不同设备语音质量差异。
- 在家长明确需要后，再评估跨设备进度同步。
