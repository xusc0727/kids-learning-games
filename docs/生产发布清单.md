# 童趣成长乐园生产发布清单

## 发布结论门槛

只有本清单 P0 项全部完成，才可以开放手机号账号和家庭同步。缺少正式短信或运营者信息时，保持 `SMS_PROVIDER=disabled`，不得使用控制台验证码对外服务。具体命令和回滚方法见 [`生产发布指引.md`](生产发布指引.md)。

## 一、发布前外部准备

- [ ] 个体工商户完整登记名称已经确认，写入 `PUBLIC_OPERATOR_NAME`。
- [ ] `PUBLIC_CONTACT_CHANNEL` 是用户可以实际联系到的渠道。
- [ ] `PUBLIC_PRIVACY_EMAIL` 可以收件并有人负责处理查询、更正、删除和投诉。
- [ ] 阿里云号码认证服务已开通“短信认证”，并已选择控制台当前可用的赠送签名和登录/注册模板，无需自行申请企业短信资质。
- [ ] 使用最小权限 RAM 用户 AccessKey，只授予 `dypns:SendSmsVerifyCode` 和 `dypns:CheckSmsVerifyCode` 所需权限。
- [ ] `AI_STORY_GENERATION_ENABLED=false`，页面无个性故事入口，生成接口返回“暂未开放”。
- [ ] 阿里云号码认证相关处理内容已经在隐私政策和儿童规则中展示。
- [ ] 用户协议、隐私政策和儿童个人信息处理规则由运营者最终审阅。

## 二、服务器与密钥

- [ ] `.env` 放在 `/etc/playmori/playmori.env` 或等效受限位置，使用 `root:playmori 640` 或同等受限权限，不放在网站公开目录。
- [ ] `ACCOUNT_IDENTITY_HASH_SECRET`、`ACCOUNT_IDENTITY_ENCRYPTION_KEY`、`PHONE_OTP_SECRET` 和 `ANALYTICS_SALT` 分别生成且互不复用。
- [ ] `NODE_ENV=production`、`HOST=127.0.0.1`、`SESSION_COOKIE_SECURE=true`。
- [ ] Node 端口只监听本机，安全组和防火墙不向公网开放 4173。
- [ ] RDS 使用独立最小权限账号、内网连接、白名单和自动备份。
- [ ] 安装 `ops/playmori.service.example`、Nginx 示例和备份 timer，并替换实际路径。

可以使用 `openssl rand -hex 32` 分别生成三组密钥；密钥只记录在安全配置系统中。身份加密密钥一旦用于真实数据，不能直接更换。

## 三、发布顺序

```bash
npm ci
npm audit --omit=dev
npm test
sudo -u playmori env PLAYMORI_ENV_FILE=/etc/playmori/playmori.env npm run db:backup
sudo -u playmori env PLAYMORI_ENV_FILE=/etc/playmori/playmori.env npm run db:migrate
sudo -u playmori env PLAYMORI_ENV_FILE=/etc/playmori/playmori.env npm run db:check
sudo -u playmori env PLAYMORI_ENV_FILE=/etc/playmori/playmori.env npm run check:production
sudo nginx -t
sudo systemctl restart playmori
sudo systemctl status playmori --no-pager
```

先备份、再迁移、最后切换应用。`007_add_production_readiness.sql` 只增加验证码协议版本字段和注销审计表，保留迁移后的数据库也可以回滚到上一版应用。

## 四、上线验收

- [ ] 本机使用 Tailscale Exit Node 时，仅在验证期间为生产服务器添加临时直连主机路由，并确认流量经过物理接口。
- [ ] `GET /api/health` 返回数据库连接正常、短信渠道为 `aliyun-auth`、核验方式为 `aliyun-auth`。
- [ ] `HEAD /.env`、`HEAD /.git/config`、`HEAD /server/config.mjs` 均返回 404。
- [ ] 页面响应包含 CSP、`X-Frame-Options: DENY`、`nosniff`、Permissions Policy 和 HSTS。
- [ ] 使用真实手机号完成验证码发送、错误码、过期、重放和五次错误尝试测试。
- [ ] 首次登录创建一个成人账号、一个家庭和一个空白默认儿童使用位。
- [ ] 未勾选儿童规则时同步被拒绝；勾选后成功并产生版本化同意记录。
- [ ] 换一台设备登录后能找回故事、收藏和识字记录。
- [ ] 清空成长数据会删除故事、收藏、进度和设备认领，并记录 `withdrawn`。
- [ ] 刚登录 15 分钟内可注销账号；注销后原 Session 失效且手机号可以重新注册。
- [ ] Nginx 日志、应用日志和 systemd 重启行为正常，不记录验证码、完整手机号或密钥。
- [ ] 本次验证创建的临时直连路由已删除；验证失败或中断时也已执行清理，并确认没有误删原有用户路由。

## 五、备份恢复演练

每日 timer 执行 `npm run db:backup`，生成权限为 `600` 的 gzip SQL，默认保留 30 天。上线前必须把最新备份恢复到一套空白测试库并运行：

```bash
gzip -dc /var/backups/playmori/<备份文件>.sql.gz | mysql -h <测试库地址> -u <恢复账号> -p <测试库名>
npm run db:check
```

至少每季度做一次恢复演练。备份应另有跨机器或对象存储副本，并按相同安全级别控制访问。

## 六、回滚

1. 停止新版本服务，但保留 Nginx 维护页。
2. 切回上一个 Git 版本并执行 `npm ci`。
3. 不回滚已经成功执行的追加式迁移；上一版应用可忽略新增可空字段和审计表。
4. 如果迁移执行中断或业务数据损坏，恢复发布前备份到新库，核验后切换数据库连接。
5. 回滚后复查登录、故事读取和匿名功能，并记录事件原因。

## 七、当前仍需人工填写

正式发布前必须确认以下三项真实值：

- 个体工商户完整登记名称；
- 用户可联系到的渠道；
- 可实际收件的隐私邮箱。

这些值通过环境变量提供给 `/api/legal`，法律页面会自动展示；生产启动校验会阻止空值上线。
